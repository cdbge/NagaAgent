### 1.2 动效词汇（JS 反推）

| 标识 | 含义 |
|---|---|
| `unseal` / `seal` / `_unsealed` | 拆封（首屏进入） |
| `stamp` / `stamping` | 盖章（确认/归档） |
| `initReveals` / `data-rev` | 显影（滚动到视口时浮现） |
| `type` | 打字机（文字逐字） |
| `requestAnimationFrame` ×9 / `cancelAnimationFrame` ×3 | 逐帧驱动，非 CSS keyframes |

### 1.3 完整 CSS 动效表（实测值）

| 场景 | 规则 | 解读 |
|---|---|---|
| 链接 / 边框 | `color .2s, border-color .2s` | 微反馈 **.2s** |
| 帮助提示 | `background .18s, color .18s` | 最快档 **.18s** |
| **显影** | `opacity .62s ease, visibility .62s` | **.62s**，`visibility` 绑同一时长（隐藏后立即脱离事件、动画中不闪） |
| **入场** | `transform .8s cubic-bezier(.7,0,.2,1), opacity .5s .35s` | 位移 **.8s** 自定义曲线 + 透明度**延迟 .35s** |
| 印章静止 | `transform: rotate(-7deg)` | 永久倾斜 7° |
| 印章 hover | `transform .3s, box-shadow .3s` | **.3s** |
| **拆封** | `translateY(26px) rotate(6deg) scale(.9)` + `opacity:0`，`.5s` | 向下 26px + 转 6° + 缩 0.9 |
| 按钮 | `.2s` | |
| 网格叠加 | `opacity 0→1，.25s` | G 键切换 |
| **数据版** | `opacity .72s, transform .72s cubic-bezier(.33,1,.68,1), filter .72s` | 三属性同步 **.72s** |
| 图版 | `transform .3s cubic-bezier(.33,1,.68,1), box-shadow .3s` | |
| **无障碍** | `[data-rev]{opacity:1;transform:none;filter:none;transition:none}` | `prefers-reduced-motion` 全关 |

### 1.4 两个贝塞尔曲线

| 曲线 | 名称 | 落点 |
|---|---|---|
| `cubic-bezier(.33,1,.68,1)` | **outCubic** | 显影 .72s、图版 .3s |
| `cubic-bezier(.7,0,.2,1)` | 慢起急收 | 入场位移 .8s |

**关键结论：全站零 `@keyframes`。** 动效由 `transition` + `requestAnimationFrame` 构成 —— 这保证"过渡"而非"弹跳"，符合机械感纪律。

|---|---|

**验收**：两套主题的"装置"完全不同，一眼能分辨。

### P4 · 动效层（3 天）

统一动效库 `ui/styles/motion.py`（已有基础，需扩充）：

| 动效 | 少女前线 | 莱茵生命 |
|---|---|---|
| 入场 | 扫描线扫过 + 锁定（`.2s`） | **压印**：落 8px + 淡入（`.3s` outCubic） |
| 列表项 | 依次点亮（`.12s` 间隔） | **显影**：`.62s` opacity + `visibility` 同绑 |
| 面板 | 滑入（`.2s`） | 拆封：位移 `.8s` + 透明度延迟 `.35s` |
| 数字 | 跳变 | **里程计**（`OutExpo`） |
| 线条 | 瞬间 | **按进度绘制** |
| 确认 | 锁定音 + 闪烁 | **盖章** `rotate(-7deg)`，`.5s` |
| 过渡 | 快切 `.12s` | 翻页 `.6s` |

**验收**：两套动效的节奏感明显不同（快 vs 慢、扫 vs 压）。

### P5 · 打磨层（2 天）

- `prefers-reduced-motion` 等价物：设置里加「减少动效」开关，全部 `transition:none`
- 无障碍：键盘导航、焦点环
- 截图对比：每套主题 6 张关键页面存档

## 五、技术约束

| 约束 | 说明 |
|---|---|
| **不能上 Electron** | 现有是 PyQt5，QSS 能力有限，复杂布局需 QPainter 自绘 |
| **动效走 Qt** | `QPropertyAnimation` + 自定义缓动（`QEasingCurve.BezierSpline` 可映射 CSS 贝塞尔） |
| **QSS 无 `visibility` 技巧** | 需用 `setVisible` + 动画结束信号手动复现 |
| **无 `@keyframes` 等价物** | 循环动画需 `QTimer` 或 rAF 等价（`QAbstractAnimation`） |
| **字体已就位** | Montserrat / JetBrains Mono 随包，中文用系统雅黑 |

## 六、风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| 手绘组件（标题栏/侧边栏/Live2D 侧栏）改造成本高 | P1 超期 | 先搭骨架，这三个最后适配 |
| 纸色主题下 Live2D 形象对比度 | 观感差 | 给形象加取景框 + 底衬，不改模型 |
| 动效过多导致卡顿 | 体验差 | 统一走 `animation_duration` 配置，提供"减少动效"开关 |
| 现有 310 处硬编码颜色 | 两套主题不彻底 | P3 一并令牌化 |
